Custom Language Parser
A simple custom programming language parser built from scratch in Go (Golang), featuring a lexer, tokenization, and parser implementation.

This project is mainly focused on learning how programming languages work internally, from source code to structured syntax.

## 📁 Project Structure

```text
custom-language-parser/
│
├── archives/       # Previous versions and experiments
│
├── src/
│   ├── ast/        # Abstract Syntax Tree definitions
│   ├── lexer/      # Lexical analysis and tokenization
│   ├── parser/     # Parser and grammar implementation
│   └── main.go     # Application entry point

```
